# Simple Interest Calculator

A simple Bash script that calculates simple interest using the principal amount, annual rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Usage

1. Make the script executable:
   ```bash
   chmod +x simple-interest.sh
   ```
2. Run it:
   ```bash
   ./simple-interest.sh
   ```
3. Enter the principal amount, annual rate of interest, and time period when prompted.

## Example

For principal `1000`, rate `5`, and time `2`, the simple interest is `100`.
